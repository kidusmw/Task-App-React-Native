# TaskApp 📱

> A learning project — don't judge the commits, judge the progress.

## What is this?

This is a **React Native learning project** built incrementally as I explore mobile development. The app starts as a simple Task Manager and will be deliberately over-engineered over time as new concepts are introduced.

If you're looking for clean, production-ready code — wrong repo. If you're looking for an honest learning journey — welcome.

## Learning Goals

- Get comfortable with React Native core concepts
- Understand navigation patterns (Stack, Tab)
- Work with local storage (AsyncStorage)
- Build real UI with styling and components
- Progressively add complexity as knowledge grows

## Tech Stack

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [React Navigation](https://reactnavigation.org/)
- [AsyncStorage](https://react-native-async-storage.github.io/async-storage/)
